# Security Policy

## Supported versions

| Version line | Supported |
| --- | --- |
| 1.0.x | Yes |
| Earlier versions | No |

## Reporting a vulnerability

Do not report suspected vulnerabilities through a public issue, discussion, or
pull request. Use this repository's GitHub private vulnerability-reporting
channel when it is available. Repository maintainers should keep that GitHub
setting enabled.

If private reporting is temporarily unavailable, contact a repository owner
privately through GitHub and include enough information to reproduce the issue:
affected version and platform, impact, reproduction steps, and any proposed
mitigation. Please allow maintainers to coordinate a fix before public
disclosure.

This policy covers the terminal application, its CLP parser and transport,
desktop integration, bundled configuration examples, and release artifacts.
The separate Rust SDK has its own matching policy in its repository.
